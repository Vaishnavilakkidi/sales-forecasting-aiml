# 📊 Sales Forecasting System using AI/ML

## 📌 Project Overview
The Sales Forecasting System is a beginner-level Machine Learning project that predicts future sales based on historical data. The system uses **Linear Regression** and **Random Forest Regressor** models to analyze trends and forecast sales, helping businesses make data-driven decisions.

---

## 🎯 Objectives
- Predict future sales using historical sales data  
- Compare the performance of Linear Regression and Random Forest models  
- Visualize actual vs predicted sales  
- Understand basic Machine Learning workflow  

---

## 🧠 Machine Learning Models Used
- **Linear Regression** – Baseline model for prediction  
- **Random Forest Regressor** – Ensemble model for improved accuracy  

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Libraries:**  
  - Pandas  
  - NumPy  
  - Matplotlib  
  - Scikit-learn  
- **Tools:** VS Code, GitHub
